# JDBM – Janitor Jibesh Database Monk

A tiny headless CMS: create custom tables in a web UI, add records, and get a REST API for every table.

This repository contains the **setup guide website** (`index.html`, a single static file).

## Host it
GitHub Pages: Settings → Pages → deploy from branch `main`, folder `/ (root)`.

## Edit it
All links, env variables and commands live in the `CFG` object at the top of the `<script>` in `index.html`.
